KOLX — วิธีเปิดเว็บด้วยตัวเอง

สำหรับ Windows
1. ต้องมี Python 3 ติดตั้งอยู่ในเครื่อง
2. แตกไฟล์ ZIP ทั้งหมดก่อน อย่ารันจากใน ZIP
3. เปิดโฟลเดอร์ KOLX แล้วดับเบิลคลิก OPEN-KOLX.cmd
4. เบราว์เซอร์จะเปิดเว็บให้เองที่ http://127.0.0.1:3000/

ระหว่างใช้งาน ให้เปิดหน้าต่างคำสั่งที่เปิดขึ้นมาค้างไว้
เมื่อต้องการหยุดเว็บ ให้กด Ctrl+C ในหน้าต่างนั้น หรือปิดหน้าต่าง
ถ้าเว็บรันอยู่แล้ว ตัวเปิดจะเปิดเว็บเดิม ไม่เปิดเซิร์ฟเวอร์ซ้ำ

ไม่ต้องติดตั้ง Node.js ไม่ต้อง npm install และไม่ต้อง Build ใหม่
ไฟล์เว็บพร้อมใช้ในโฟลเดอร์ out กรุณาเก็บไว้คู่กับ launch.py

ถ้าต้องการพิมพ์คำสั่งเอง:
เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ python launch.py
บน macOS/Linux ที่ติดตั้ง Python 3 ให้ใช้ python3 launch.py

ลิงก์ 127.0.0.1 เปิดได้เฉพาะเครื่องที่รัน
การเปิดจากโทรศัพท์ หรือแชร์ให้ผู้อื่น ต้องตั้งค่าการเข้าถึงเพิ่มเติมหรือใช้เว็บโฮสติ้ง
